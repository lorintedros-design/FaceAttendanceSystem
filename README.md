# Face Attendance System

A Python-based Face Attendance System that uses a webcam and face recognition to automatically record student attendance.

## Features

- Register students using their face
- Detect faces using OpenCV
- Recognize registered students
- Automatically record attendance
- Store attendance with date and time
- Reduce manual attendance work

## Technologies Used

- Python
- OpenCV
- face_recognition
- Haar Cascade
- CSV
